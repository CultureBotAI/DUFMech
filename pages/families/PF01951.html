Source description

This archease family of proteins [InterPro reference PUB00109176], has two SHS2 domains [InterPro reference PUB00057445], with one inserted into another. It is predicted to be an enzyme [InterPro reference PUB00057445]. It is predicted to act as a chaperone in DNA/RNA metabolism [InterPro reference PUB00109176].
