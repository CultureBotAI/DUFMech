Reference residues D126, D159, D160, D179, E228, E259, Y295, Y316 and T350

2019 Table 4 primer translation, aligned to Q5JIZ3, exposes an internal
numbering discrepancy. Published E339Q-Fw translates ITVGQQLYDDE, uniquely
matching reference 336-346 except E341Q. D342N-Fw translates QELYNDEESS,
matching 340-349 except D344N. D343N-Fw translates QELYDNEESSTT, matching
340-351 except D345N. The quadruple primer translates ELYNNQQSSTT (then stop),
matching 341-351 except D344N/D345N/E346Q/E347Q. Thus retain published mutant
labels, paired with primer-supported reference coordinates, not silently relabelled
as independently resequenced clones. The five claimed acidic sites map to
E341/D344/D345/E346/E347, not literal E339/D342/D343/E344/E345 in this reference.
The paper's 343-YDDEESSTT tail numbering does agree with the reference.

Q72L89 sequence version 1, 353 aa, TT_C0171, T. thermophilus HB27,
taxon 262724, exactly equals AAS80519.1. PF01861 spans 115-351 inclusive.
6J27 is 374 aa: the same 20-aa tag, followed by MV and reference residues 2-353.
This differs from the reference's initial M, consistent with the cloned GTG
after the NdeI initiation codon. 6J28 is 375 aa and retains this N terminus,
replacing reference 346-353 QDEEATTY with YDDEESSTT. The replacement overlaps
PF01861 but extends beyond its endpoint; it is not an isolated-domain exchange.

not independent sequencing of the historical enzyme assay aliquots.
