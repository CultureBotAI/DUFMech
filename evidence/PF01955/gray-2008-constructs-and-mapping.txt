Main construction Methods state that all cloned cbiZ inserts were sequenced
with pBAD5prime/pBAD3prime. Actual historical sequences, donor-strain TableS3
and primer TableS4 were not retrieved. PMC's downloaded HTML does not contain
those supplement files; current web PMC access returned a browser challenge.
The publisher main text was accessible once through the web reader; direct
download returned403 and the supplement endpoint was inaccessible. No bypass.
Original Figures2-4 were visually inspected. Figure2 is phylogeny, not an
additional perturbation or proof that all93 searched homologs function alike.

All seven positive constructs use pBAD24, with alternative donor inserts,
not joint expression of seven genes. Rs has the R.sphaeroides coding sequence
plus3bp5prime and15bp3prime, cloned EcoRI/XbaI. Rr uses EcoRI/PstI; Bh is a
whole B.halodurans BtuD-CbiZ fusion, also EcoRI/PstI. Mm uses NcoI/SphI;
Pf uses KpnI/HindIII; Mj uses NcoI/HindIII; Fa uses KpnI/HindIII. The extract
is not the MBP/His6-tagged preparation of the later2009 remodeling paper.
